Packages

Python packages of IFDD on PyPI, published by ifdd.de contributors. Source code, issues and changelogs are in the GitHub repositories.

DistributionImportPurposeLinks
ifdd-be-core ifdd.be.core Shared runtime of the IFDD JSON-LD backend: bitemporal storage, JSON-LD processing, OIDC, access rights, API documentation. Services are generated from the be template. PyPI
GitHub
ifdd-ts-core ifdd.ts.core Shared runtime of the IFDD time series API: token and store checks, checks of samples against the vocabularies, reading and writing in VictoriaMetrics. Services are generated from the ts-api template. PyPI
GitHub

Install

pip install ifdd-be-core
pip install ifdd-ts-core

The packages are the runtime of services generated from the templates; the templates bring the matching version. Versions follow the scheme YY.MM.N: year, month and a running number.

Questions and problems

Please open an issue in the repository of the package. For anything else: maintainers@ifdd.de.
