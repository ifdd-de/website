Pakete

Python-Pakete von IFDD auf PyPI, veröffentlicht von den ifdd.de contributors. Quelltext, Issues und Changelogs liegen in den GitHub-Repositories.

PaketImportZweckLinks
ifdd-be-core ifdd.be.core Gemeinsame Laufzeit des IFDD-JSON-LD-Backends: bitemporale Speicherung, JSON-LD-Verarbeitung, OIDC, Zugriffsrechte, API-Dokumentation. Dienste entstehen aus dem Template be. PyPI
GitHub
ifdd-ts-core ifdd.ts.core Gemeinsame Laufzeit der IFDD-Zeitreihen-API: Prüfung von Tokens und Speicherorten, Prüfung der Werte gegen die Vokabulare, Lesen und Schreiben in VictoriaMetrics. Dienste entstehen aus dem Template ts-api. PyPI
GitHub

Installation

pip install ifdd-be-core
pip install ifdd-ts-core

Die Pakete sind die Laufzeit der Dienste, die aus den Templates entstehen; die Templates bringen die passende Version mit. Versionen folgen dem Schema JJ.MM.N: Jahr, Monat und eine laufende Nummer.

Fragen und Probleme

Bitte ein Issue im Repository des Pakets anlegen (gern englisch). Für alles andere: maintainers@ifdd.de.
