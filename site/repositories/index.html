Repositories

All repositories of the GitHub organisation ifdd-de are public and licensed under BSD-3-Clause.

Each service is a cookiecutter template. An operator generates an instance with cruft and keeps it in a repository of their own; cruft update brings later template changes in.

Concept

overview Concepts, naming rules, decisions and brand assets.

Service templates

proxy Reverse proxy (Traefik) with TLS, security headers and an optional login gate.
keycloak Identity provider (OIDC) with the IFDD realm and database backup.
be JSON-LD backend: stores records bitemporally and checks access rights per context.
ui Read-only web frontend (react-admin).
schema Static service for the JSON-LD contexts.
type Static service for the vocabularies: labels, help texts, order.
unit Static service for units and quantity kinds, linked to QUDT.
ct Core tools: a CLI that generates, checks and loads JSON-LD records.
ts Time series: VictoriaMetrics and Grafana.
ts-api REST interface for reading and writing time series.
wf Workflows: Kestra with Jupyter notebooks.

Packages

be-core Python package ifdd-be-core, runtime of be.
ts-core Python package ifdd-ts-core, runtime of ts-api.

Tools

tools-pentest Containerised vulnerability scanning — for your own systems only.
